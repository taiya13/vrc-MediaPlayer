# Phase6-4 — 誰でも使える Catalog Builder と MediaPlayer

Phase6-3 で「取り込む → 保存 → 焼く」が一本につながりました。
Phase6-4 は**機能を増やすのではなく、すでにあるものを使えるようにする**回です。

新しく足したクラスは 4 つで、**うち 3 つは Unity にも YouTube にも依存しません**。
判断はぜんぶ EditMode で検証できる場所に置いてあります。

---

## 1. Catalog Builder

### ① 取得結果をクリア

取り込みバーに **「取得結果をクリア」** を追加しました。
結果が残ったまま次を取ると、どちらを見ているのか分からなくなります。
押すと結果一覧とサムネイルの両方が消えます（編集中のカタログは無事です）。

### ② チャンネルごとにまとめる

`CatalogItemGrouping`（新規・純粋 C#）

```
▼ ○○チャンネル  (12 / 40 件・うち 8 件はあり)
   ☑ 曲名 A                     3:45
   ☑ 曲名 B                     4:12
▶ △△チャンネル  (0 / 15 件)
```

- **まとまりの左のチェックで丸ごと入り／切り**ができます
- ジャンルごと・取り込み元ごと・まとめない にも切り替えられます
- **たたんだ状態は取り込み直しても引き継ぎます**（毎回開くとたたむ意味がない）
- **まとめる鍵は `Artist` / `Genre` / `Source`** — YouTube 固有の言葉は一切出てきません。
  JSON/CSV Importer を足しても、このクラスは 1 行も変わりません

### ③ 同じ動画 ID は重複しない

混ぜ方を入れ替えました。

| 混ぜ方 | 同じ ID があったら | |
|---|---|---|
| **すでにあるものは飛ばす** | 何もしない | **新しい既定** |
| すでにあるものを新しくする | 上書き（**手で足した関連は残す**） | |
| いまの中身を捨てて入れ替え | 全消しして入れる | |

これまでの既定（`MergeAppend`）は同じ ID を `abc` / `abc-2` とずらして入れていました。
同じチャンネルを 2 回取り込むと**ワールドの一覧が二重になります**。
定数自体は「意図して複製したいとき」のために残していますが、**窓の選択肢からは外しました**。

ボタンにも実際に増える数を出します — 「② 選んだ 40 件を追加する**(増えるのは 8 件)**」。

### ④ 関連（RelatedIds）の自動生成

`RelatedIdGenerator`（新規・純粋 C#）

近さの点数：

| 共通点 | 点 |
|---|---|
| 同じチャンネル | 3 |
| 同じジャンル | 2 |
| 同じタグ 1 つにつき | 1 |

- **0 点のものは関連にしません。** 共通点の無いものを並べても「おすすめ」になりません
- 点の高い順、同点ならカタログの順 → **同じ入力からは必ず同じ結果**
- **手で書いたものは壊しません。** 「空いているものだけ作る」は既に入っている行を飛ばします。
  全部作り直すのは確認ダイアログを挟んだ別ボタンです
- 1 件だけ作り直すボタンも編集欄にあります
- 重み・上限・どれを見るかは「細かい設定」で変えられます
- 取り込み後に自動で走らせる／走らせないはチェックボックス 1 つ

ジャンルとタグの材料は YouTube 側から増やしました（`videos.list` の `snippet` に
もともと入っているので**通信は増えません**）。

- `categoryId` → `YouTubeCategoryNames` で日本語のジャンル名に
- `tags` → 先頭 8 個まで（30 個入れると編集画面がタグで埋まる）

> **推薦エンジン（Phase1-3）とは別物です。** あちらは再生中に「次に何をかけるか」を決めます。
> ここは編集時の下ごしらえで、ワールドには 1 行も入りません。

### ⑤ サムネイルを出す

`CatalogThumbnailCache`（新規・Editor 専用）

- 左の一覧・取得結果・編集欄の 3 か所に出ます
- **プロジェクトには 1 枚も保存しません**（メモリだけ）。
  ワールドの容量が増えず、窓を閉じれば消えます
- **待ちません。** まだ無ければ同じ大きさの枠だけ描き、届いた時点で描き直します
  （取れた瞬間に行の高さが変わって押す場所がずれるのを防ぐため）
- 同時に取りに行くのは 4 枚まで。200 件を一度に投げると Unity が固まります
- 「絵を出す」チェックで丸ごと切れます

### ⑥ 検索・絞り込み

`CatalogItemFilter`（新規・純粋 C#）

```
絞り込み [あさ        ] [チャンネル:すべて▼] [ジャンル:すべて▼] [タグ:すべて▼] [作りかけだけ] [解除]
```

- 検索欄は**見出し・チャンネル・ジャンル・タグ・ID を横断**。
  **空白区切りは AND**（「ボカロ 2023」で両方を含むものだけ）
- チャンネル／ジャンル／タグは**実際に入っている値からプルダウン**で選びます
  （打ち間違いだと 1 件も出ずに理由が分からないため）
- 「作りかけだけ」で、URL が欠けている行だけを拾って直せます
- **絞り込んでも編集先はずれません。** 一覧が持っているのは**元の位置の番号**だからです
  （並べ替えたコピーではありません）
- 絞り込み中は ▲▼ の並べ替えだけ止まります。見えている隣と本当の隣が違うためです

## 2. MediaPlayer UI

### ⑦ 表示を日本語に

| 前 | 後 |
|---|---|
| Library | すべての曲 |
| Queue | 再生予定 |
| Related / 関連 | おすすめ |
| （見出し無し） | 再生中 |

**内部のクラス名・GameObject 名・イベント名は 1 つも変えていません。**
`UdonMediaListView` / `SourceLibrary` / `ScrollDown` などはそのままです。

**Prefab の再配線は要りません。** `HeaderLabel` の既定を空にして、
`EffectiveHeader()` が `Source` から決めるようにしました。

- 新しく組み立てた Prefab → そのまま日本語
- **すでにワールドに置いてある Prefab** → `Tools > Smart Media Platform > 操作 UI の配線を繋ぎ直す`
  を 1 回押すだけ（古い `Library` / `Queue` を空に戻して既定に任せます）
- 自分で付けた見出しは**そのまま残します**

「再生予定に追加」「再生予定から外す」など、押したときの案内文も日本語にしました。

### ⑧ 一覧操作

**a. ▲▼ 1 回の量を「1 画面 − 1 行」に**

1 画面ずつだと見ていた行が全部入れ替わって、どこまで見たか分からなくなります。
**1 行だけ残す**と、その行が目印になって続きから読めます。

**b. 続けて押すと速くなる**

```
1 回目 →  5 行
2 回目 →  9 行
3 回目 → 16 行
4 回目 → 29 行 …（上限 64 行）
```

- 0.45 秒以内に続けて押すと「連打」とみなして 1.8 倍ずつ
- **向きを変えたら初めに戻します**（行き過ぎて戻すときに戻しすぎない）
- 400 件の一覧でも**十数回で端まで**届きます（テストで検証済み）

**c. ▲▲ ＝ 迷子からの復帰**

見出しの行にボタンを 1 つ足しました。

- 「すべての曲」では → **さっきかけた曲の場所へ**
- 「再生予定」では → 先頭（＝ いま鳴っているもの）へ
- 鳴っているものがこの一覧に無ければ → 先頭へ

**1 つのボタンで、どちらの一覧でも正しいことをします。**
戻る先が無いときは自動で隠れます。

> **ホイール操作は入れていません。** VRChat の Udon で `UnityEngine.Input` が
> 使えるかを**この環境では確かめられず**、もし弾かれると
> **UdonSharp のコンパイルがプロジェクト全体で止まります**。
> Phase5-3 で「押せない」を 2 回踏んでいるので、確認できないものは入れない判断にしました。
> また**ホイールは VR では効きません** — VR で効くのは b と c です。
> 実機で `Input` が通ることを確認できれば、`UdonMediaListView` に 10 行ほどで足せます。

## 3. 変えたクラス

### 新規

| クラス | 場所 | Unity 依存 |
|---|---|---|
| `CatalogItemFilter` | CatalogBuilder/Runtime | なし |
| `CatalogItemGrouping` | CatalogBuilder/Runtime | なし |
| `RelatedIdGenerator` | CatalogBuilder/Runtime | なし |
| `YouTubeCategoryNames` | Importers/YouTube | なし |
| `CatalogThumbnailCache` | CatalogBuilder/Editor | Editor 専用 |

### 変更

| クラス | 何を |
|---|---|
| `CatalogDraft` | `MergeSkip` 追加 / `MergeAppend` を選択肢から外す / `CountNew` / 上書き時に関連を残す |
| `CatalogImportSelection` | `Grouping` を持つ / まとまりごとの選択 |
| `CatalogBuilderWindow` | 絞り込みバー / まとめ表示 / サムネイル / 関連バー / クリアボタン |
| `YouTubeVideoInfo` | `Tags` / `CategoryId` / ジャンルとタグを `ToDraftItem` へ |
| `YouTubeDataApiClient` | `snippet` から `tags` / `categoryId` を読む（通信は増えません） |
| `ListScrollModel`（正典） | ステップを「1 画面 − 1 行」に / 連打の加速 |
| `UdonMediaListView` | 同上の写し / `EffectiveHeader()` / `ScrollHome()` / `NowPlayingPosition()` |
| `UdonMediaPanelBuilder` | 日本語見出し / ▲▲ ボタン / 「再生中」の見出し |
| `UdonMediaPanelDoctor` | `ScrollHome` の配線 / 英語見出しの修復 |
| `UdonTransportView` | 案内文の日本語化 |

**責務は 1 つも動かしていません。** Importer は取ってくるだけ、`CatalogDraft` は編集中の入れ物、
窓は見せて伝えるだけ、MediaPlayer は表示と再生だけです。

## 5. さらに改善できる点

**次に効きそうな順：**

1. **焼いた内容と Catalog.asset のズレ検出**（Phase6-3 から持ち越し）
   保存したあと焼き忘れても分かりません
2. **差分更新** — 前回取り込みとの差、特に**消えた動画の検出**
3. **サムネイルをアセットとして持つ** — ワールド内のパネルにも絵を出す。
   容量の設計が要ります
4. **ホイール操作** — Udon の許可リストを実機で確認してから
5. **並べ替え** — 長さ・公開日・50 音順。いまは取り込んだ順のみ
6. **一覧の頭出し** — 「あ行」ジャンプ。日本語と英語が混ざると難しい
7. **複数チャンネルのまとめ取り込み** — いまは 1 URL ずつ
8. **関連の重みをプリセットに** — 「チャンネル重視」「ジャンル重視」など
